
## 2024-05-18 - [Fix Command Injection in getClipboardCommands]
**Vulnerability:** A command injection vulnerability existed in `src/utils/imagePaste.ts` where the `CLAUDE_CODE_TMPDIR` environment variable was used to construct `screenshotPath`. This path was then directly interpolated into string shell commands (e.g., `osascript`, `xclip`, `powershell`) that were executed via `execa` with `shell: true`. A maliciously crafted `CLAUDE_CODE_TMPDIR` (e.g., `/tmp/test" && echo "pwned" && "`) would allow arbitrary command execution.
**Learning:** Shell commands requiring `shell: true` (such as AppleScript multi-line commands or pipes) that incorporate dynamic user-controlled strings are highly vulnerable if the string is interpolated directly into the command string.
**Prevention:** Rather than using string interpolation for dynamic variables within shell commands, utilize the shell's or command execution framework's native environment variables. Pass the dynamic value through `execa`'s `env` object, and access it securely within the script (e.g., `system attribute "VAR"` in AppleScript, `"$VAR"` in bash, or `$env:VAR` in PowerShell). This separates the command structure from the data, neutralizing injection payloads. Additionally, natively process paths using file system libraries (e.g., `fs.unlink`) rather than shelling out to cleanup files (`rm` or `del`).

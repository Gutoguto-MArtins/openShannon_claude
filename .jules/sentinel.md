## 2024-05-20 - Prevent Command Injection via OS Clipboard Command Builders
**Vulnerability:** Shell command injection risk via unescaped environment variables (`CLAUDE_CODE_TMPDIR` and `TEMP`) used to construct paths interpolated directly into shell commands (`rm`, `osascript`, `powershell`) with `execa(..., {shell: true})`.
**Learning:** Even internal environment variables that control paths can be attack vectors if they are piped straight into `shell: true` executions. Shell implementations on different platforms require distinct and careful validation to ensure inputs do not break command strings.
**Prevention:** Always validate path-defining environment variables against shell metacharacters before using them in commands. Avoid `shell: true` executions for operations that can be handled natively by Node.js APIs (e.g., replace `rm -f / del /f` with `fs.unlink`). For mandatory shell execution, escape dynamic variables correctly depending on the interpreter (e.g., replacing `'` with `''` for PowerShell).

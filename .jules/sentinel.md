## 2024-06-20 - Command injection vulnerability in `which` utility
**Vulnerability:** Command injection in `which` (src/utils/which.ts). The user-supplied `command` was passed directly into `execa` with `shell: true` and `execSync` via string interpolation (`which ${command}` and `where.exe ${command}`). This allowed arbitrary shell commands to be executed if an attacker could control the `command` argument (e.g. `node && touch /tmp/pwned1`).
**Learning:** Utilities intended to wrap built-in commands like `which` often improperly use shell string interpolation for convenience. Using `shell: true` or `execSync` makes it vulnerable to injection if inputs aren't sanitized.
**Prevention:** Always use `execa` or `execaSync` with `shell: false` and pass command-line arguments as an array instead of string concatenation. Example: `execa('which', [command], { shell: false })`. Extract output using `.stdout.trim()` and check `.exitCode !== 0`. Ensure synchronous calls use `execaSync` instead of the legacy `child_process.execSync` wrapper.

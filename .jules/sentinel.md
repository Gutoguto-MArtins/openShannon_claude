## 2025-02-23 - Prevent Command Injection in which Utility
**Vulnerability:** The `which` utility (`src/utils/which.ts`) allowed command injection by passing untrusted user input directly into `execa` with `shell: true` or `execSync_DEPRECATED`. Specifically, `await execa(\`where.exe \${command}\`, { shell: true })` and `execSync_DEPRECATED(\`which \${command}\`)` could be exploited by executing arbitrary commands via operators like `&&` or `;`.
**Learning:** Hardcoding string templates for shell executions (`which ${command}`) combined with `shell: true` introduces major security flaws, especially on command line utility wrappers which are often given untrusted user arguments. Also discovered that `execSync_DEPRECATED` operates inherently like a shell execution and shouldn't be used for dynamic input.
**Prevention:** Always use safe native Array-argument forms (e.g. `execa('which', [command], { shell: false })`) for process execution to avoid shell evaluation of untrusted strings. Replace any usage of `execSync_DEPRECATED` with `execaSync` when dealing with dynamic command inputs.

## 2025-07-06 - Shell Command Injection via CLAUDE_CODE_TMPDIR in Image Paste
**Vulnerability:** Shell command injection via `CLAUDE_CODE_TMPDIR` environment variable used in `src/utils/imagePaste.ts`. The directory path is concatenated directly into shell commands for `checkImage`, `saveImage`, `getPath`, and `deleteFile` across multiple platforms (Darwin, Linux, Win32).
**Learning:** `shell: true` and string interpolation is dangerous even for environment variables, especially if those paths contain quotes or other shell metacharacters. Instead of deleting via shell (`rm -f`), we should use native FS APIs like `fs.promises.unlink`. To mitigate the risk in shell commands we must pass dynamic values securely (e.g. via environment variables without interpolation) when possible, or just not use `shell: true` when removing files.
**Prevention:** Avoid interpolating environment variables that contain user-provided or local paths directly into shell command strings. When deleting files, use native `fs.promises.unlink` or `getFsImplementation().unlink`. For executing osascript/powershell, pass environment variables directly and fetch them within the script instead of string interpolation.

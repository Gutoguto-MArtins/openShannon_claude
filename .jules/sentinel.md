## 2025-02-27 - Command Injection in clipboard image save/delete operations via environment variables
**Vulnerability:** The dynamic path variable `screenshotPath`, which could be derived from the user-controlled `process.env.CLAUDE_CODE_TMPDIR`, was interpolated directly into shell strings in `src/utils/imagePaste.ts` (for both fetching images from clipboard and removing temporary images). Since these strings were passed to `execa` with `shell: true`, crafting a `CLAUDE_CODE_TMPDIR` containing bash injection vectors (`foo"; touch pwned_image_paste; "bar`) led to arbitrary command execution when the code tried to run `rm -f "foo"; touch pwned_image_paste; "bar/claude_cli_latest_screenshot.png"`.
**Learning:** Even internal tool commands must avoid string interpolation if variables are derived from the environment. `shell: true` execution with string interpolation creates injection risks even in desktop applications, since attackers can manipulate environment variables for local privilege escalation or arbitrary execution in different contexts.
**Prevention:** Rather than performing string interpolation with paths, dynamic variables for scripts executed with `shell: true` should be passed securely through environment variables. For file deletion operations, use native file system APIs like `getFsImplementation().unlink(path)` instead of spawning a shell command to delete a file.

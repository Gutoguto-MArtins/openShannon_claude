## 2024-05-18 - Shell Injection vulnerabilities using execSync_DEPRECATED
**Vulnerability:** Found uses of `execSync_DEPRECATED(\`...\`)` where dynamic inputs like `path` and `filePath` were directly interpolated into a command string, allowing shell command injection. Also found execution of shell `dir` when a native filesystem method is perfectly sufficient.
**Learning:** Legacy `execSync_DEPRECATED` wraps native child_process `execSync` which inherently runs in a shell. Passing untrusted variables to these legacy wrapped functions is highly risky.
**Prevention:** Instead of interpolating arguments into a single string for shell execution, use `execaSync` (or `execa`) with `shell: false` (or undefined) and pass arguments as an array. If parsing a configurable command string with arguments is necessary, use `shell-quote` to safely separate the binary from its arguments. For checking if a path exists, always use `fs.existsSync` or `fs/promises` alternatives rather than shell commands like `dir`.

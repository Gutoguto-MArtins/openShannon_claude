## 2024-05-16 - Command Injection in `which` utility
**Vulnerability:** Command injection vulnerability identified in `src/utils/which.ts`. The `whichNodeAsync` and `whichNodeSync` functions were using `execa` with `shell: true` and string interpolation to execute user-controlled input (`which ${command}` and `where.exe ${command}`). This allowed attackers to append malicious shell commands (e.g., `which node; rm -rf /`).
**Learning:** `shell: true` combined with string interpolation is an anti-pattern for executing system utilities where arguments might be dynamic or user-controlled. Even simple utilities like `which` can become vectors if their input is unsanitized.
**Prevention:** Always use `execa` with `shell: false` (the default) and pass arguments as an array (e.g., `execa('which', [command])`). This forces the underlying system to treat the input purely as arguments rather than executable shell code. When synchronous execution is required, use `execaSync` similarly instead of `execSync_DEPRECATED`.

## 2025-02-14 - Fix Command Injection in which utility
**Vulnerability:** Command injection vulnerability in `src/utils/which.ts` when resolving executable paths. Functions `whichNodeAsync` and `whichNodeSync` used `execa` with `shell: true` and `execSync_DEPRECATED` (which uses a shell by default) alongside string interpolation, allowing an attacker or untrusted input to append arbitrary commands.
**Learning:** Utilities that execute shell commands to query system state (like `which` or `where.exe`) are prime targets for command injection when they naively append input to a command string rather than safely passing it as an argument array. Additionally, wrappers like `execSync_DEPRECATED` often hide default shell execution behaviors.
**Prevention:** Avoid `shell: true` entirely when executing dynamic or unsanitized inputs. Always pass commands and arguments as array elements using `execa` or `execaSync` with `shell: false`. Prefer native or specialized libraries over manually invoking shell utilities where possible.

## 2025-02-28 - Sentinel fixes Command Injection in src/utils/which.ts
**Vulnerability:** Command injection vulnerability in `src/utils/which.ts` functions (`whichNodeAsync`, `whichNodeSync`) because user-provided command string inputs were passed directly into string templates (`where.exe ${command}`, `which ${command}`) executed via `execa` and `execSync_DEPRECATED` with `shell: true`.
**Learning:** Hardcoding string commands with string interpolation using unvalidated user input is highly dangerous. Although they were wrapped to suppress errors via `reject: false`, an injection passing a semi-colon like `node; rm -rf /` executes the injected commands blindly. Additionally, relying on synchronous execution wrappers that use shell under the hood should be strictly avoided.
**Prevention:** Avoid string interpolation entirely when passing inputs to shell commands. Always use array arguments instead `execa('command', ['argument'])` with `shell: false`. For synchronous cases, prefer the `execaSync` wrapper provided natively by `execa` using array arguments and `shell: false`.

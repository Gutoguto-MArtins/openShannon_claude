## 2025-02-21 - Replace `execSync_DEPRECATED` shell execution with secure execution
**Vulnerability:** Found arbitrary command injection vulnerabilities in `src/utils/windowsPaths.ts` (`checkPathExists`, `findExecutable`) and `src/utils/promptEditor.ts` (`editFileInEditor`) where user-controlled or external paths were being interpolated directly into shell commands via `execSync_DEPRECATED(..., { shell: true })` (implied or actual).
**Learning:** Shell evaluation combined with string interpolation of external paths enables arbitrary command execution. For example, `dir "${path}"` where `path` is `foo"; touch pwned_winPaths; echo "` executes the injected command.
**Prevention:** Avoid shell executions. For file system checks, prefer native `fs` module functions (e.g., `fs.statSync`). For external process execution, avoid `shell: true`, parse configurable commands securely using `tryParseShellCommand`, and pass arguments as an array to `execaSync` or `execa` with `{ shell: false }`.

## 2024-05-18 - Command Injection in Windows Path Resolution
**Vulnerability:** Command injection in `checkPathExists` and `findExecutable` in `src/utils/windowsPaths.ts`. The variables `path` and `executable` were interpolated directly into shell strings executed via `execSync_DEPRECATED`, allowing an attacker to inject shell metacharacters and execute arbitrary code on Windows if these inputs were derived from untrusted sources.
**Learning:** Legacy synchronous shell wrappers like `execSync_DEPRECATED` are dangerous when handling variable paths. Even seemingly harmless path-checking utilities can become vectors for severe command injection if they rely on shell builtins (like `dir`) rather than native APIs.
**Prevention:** Use native Node.js filesystem APIs (`fs.statSync`) instead of shell commands to verify path existence. For external commands, use libraries like `execaSync` and pass arguments as strictly-bounded arrays rather than interpolating strings, effectively avoiding shell evaluation.
